## Requirements
- Windows 10 or later
- Visual Studio 2022
- .NET Framework 4.7.2
- MySQL Server 8.0
- MySQL Connector/NET (via NuGet)

## Setup Steps
1. Clone the repository
2. Import Database/cafe_handler.sql into MySQL
3. Open solution in Visual Studio
4. Update connection string in DBHelper.cs
5. Build and Run (F5)

## Default Login
- Admin: admin / admin123
- Cashier: cashier / cashier123
